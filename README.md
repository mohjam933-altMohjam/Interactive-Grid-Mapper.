Project Overview
This project is a console-based Python application that demonstrates the manipulation of 2-Dimensional lists (nested lists). It generates a 3x3 visual grid and prompts the user to enter a two-digit number representing the row and column. The program then updates the grid by placing an 'X' in the exact coordinates specified by the user.

Skills & Concepts Demonstrated

Data Structures: Creating and indexing 2D lists (Arrays).

User Input & Validation: Handling strings and type casting (converting string input to integers).

String Formatting: Using Python f-strings to display the grid cleanly in the console.

Zero-Indexed Logic: Adjusting user input to match Python's zero-based indexing system (subtracting 1 from the input).
